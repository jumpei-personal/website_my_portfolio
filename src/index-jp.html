加藤順平
人事データサイエンティスト

人と組織に関するデータを活用し、採用・配置・育成・人員計画などの意思決定を支援しています。 統計モデリングとAIを組み合わせ、実務で活用できる分析やツールの開発に取り組んでいます。

分析プロジェクト

人員シミュレーション基盤

入社・退職・社内異動のシナリオを踏まえ、将来の人員数を予測するための基盤。過去の従業員属性から推定した遷移確率を用いるマルコフ連鎖ベースの人員シミュレーションモデルで、10,000名以上の従業員について5つ以上の属性を扱い、戦略的な人員計画と人員規模の予測を支援します。

Problem
従来の予測プロセスは時間がかかるうえ、統計的に頑健でない確率の仮定に依存しており、人員計画における不確実性を考慮することが困難でした。
Model
マルコフ連鎖に基づく人員遷移モデル。
Algorithms
  • Markov Chain
Impact
拡張性の高い人員予測により、人員計画の精度向上を支援。

人件費シミュレーション基盤

不確実な人員変動シナリオのもとで、将来の人件費を予測するための基盤。シミュレーションした人員数を入力とするExplainable Boosting Machine（EBM）モデルを用い、複数シナリオにわたる人件費予測と予算計画を支援します。

Problem
採用・退職・社内異動といった将来の人員変動が不確実な状況では、人件費の計画が困難になります。
Model
シミュレーションした人員数を用いた、EBMベースの人件費シミュレーションモデル。
Algorithms
  • Explainable Boosting Machine (EBM)
Impact
シナリオベースの人件費予測により、予算計画の精度向上を支援。

ドライバー分析基盤

クライアントや分析テーマごとに異なるHR上の問いに対し、解釈しやすいドライバーを特定する基盤。多数のカテゴリ変数に対応し、目的変数の設定や、分析依頼ごとの個別データクレンジングが可能です。

Problem
HRデータには多くのカテゴリ変数が含まれるため、ビジネス背景の異なる頻繁なアドホック依頼に対して、通常の線形回帰やロジスティック回帰をそのまま適用することは困難でした。
Model
個別のデータクレンジングに対応できる、設定可能なドライバー分析モデル。
Algorithms
  • Explainable Boosting Machine (EBM)
  • Logistic Regression
  • Bayesian Inference
Impact
多様なHR課題に対して、解釈しやすい要因分析を提供。

離職分析

離職の可能性が高い従業員と、離職リスクが時間とともにどう変化するかを推定する分析。勾配ブースティングによる離職リスクの分類と、時間依存Coxモデルによる離職までの期間分析を組み合わせ、再現性のあるノートブックパイプラインからビジネス向けのHTMLレポートを生成します。

Problem
人事部門には、誰が離職しそうかだけでなく、いつ離職リスクが高まるのかを、ビジネス側が行動に移せる形で把握する必要がありました。
Model
離職リスクと離職までの期間を推定するモデルと、ビジネス向けレポート。
Algorithms
  • LightGBM
  • Cox Time-Varying Model

組織変化の因果効果分析

異動などの組織上の変化が、離職率などのHR指標に与える因果効果を推定する分析。各従業員がその変化を経験する確率を傾向スコアとしてモデル化し、変化あり・なしの従業員間で重み付けした結果を比較することで、選択バイアスを低減します。

Problem
単純な前後比較では、異動などの組織上の変化が、離職率などのHR指標の変化を実際に引き起こしているのかを判断できません。
Model
傾向スコアで重み付けした因果効果推定モデル。
Algorithms
  • Propensity Score (Logistic Regression)
  • Inverse Probability Weighting (IPW)

異動最適化AI（WIP）

職種名の埋め込みを用いて、より適した異動先を推薦する開発中のプロジェクト。各従業員と他の職務との距離を測定し、従業員が理想とする将来のポジションへの道筋を推定します。従来の求人推薦とは異なり、次のマッチングだけでなく、理想の職務への距離を最小化する最適な道筋を最適化します。

Problem
異動の意思決定では、現在似ている職務とのマッチングだけでなく、各従業員が理想とする将来のポジションまでの距離も考慮する必要があります。
Model
職務間の距離と理想のキャリアパスを最適化する、職種名の埋め込みモデル。
Algorithms
  • Sentence Embeddings (SBERT / BGE)
  • UMAP
  • HDBSCAN
  • K-Means
  • Agglomerative Clustering
  • Cosine Similarity
Impact
理想の職務への道筋を最短化する異動を推薦。

スキルナレッジグラフ

各職務に求められるスキルをもとに、社内での次のキャリア候補を推薦する仕組み。LLMで職種ごとのスキルを生成し、埋め込みの類似度とLLMによる判定を組み合わせてスキル間の関係をスコア化し、それを集約して職務間の類似度を算出することで、キャリア面談を支援します。

Problem
従業員はスキルや経験を持っていても社内での明確なキャリアパスが見えにくく、キャリア面談を行うカウンセラーには具体的な次の職務の提案が必要でした。
Model
社内異動の推薦に向けた、スキルベースの職務類似度モデル。
Algorithms
  • LLM Skill Generation
  • Embeddings + Cosine Similarity
  • LLM-as-Judge Scoring
